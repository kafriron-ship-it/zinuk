# זינוק

טיימר הזנקות למדריכי שיוט: ספירה לאחור עם צפירות, רולינג סטארט, דחייה והחזרה כללית, ספירה קדימה אחרי ההזנקה.
עובד בלי אינטרנט ואפשר להתקין אותו למסך הבית.

**לפתיחה:** https://kafriron-ship-it.github.io/zinuk/

## התקנה לטלפון
- **אייפון (Safari):** כפתור שיתוף ⬆︎ ← "הוסף למסך הבית".
- **אנדרואיד (Chrome):** תפריט ⋮ ← "התקן אפליקציה" / "הוסף למסך הבית".

## מבנה
- `index.html` — כל האפליקציה בקובץ אחד.
- `sw.js` — עבודה בלי אינטרנט (הדף, הצלילים, האייקונים והגופנים נשמרים במכשיר).
- `manifest.json`, `icons/` — התקנה כאפליקציה.
- `sounds/` — הקלטות.
